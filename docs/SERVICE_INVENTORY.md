# Service inventory

Every topic the original website advertises, the page it now lives on, and why labels were merged.

**Merge rule:** a label gets its own page only when it brings a different question, audience or caution. Labels that are marketing synonyms (“Love Marriage Problems” and “Love Marriage” point to the same original URL) are merged so the site never has near-identical keyword pages.

Status ✅ means the route exists, has unique copy, H1, metadata, FAQs, related links and an enquiry CTA, and is covered by the e2e route test.
